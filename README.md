# 🐍 Snake Arena: Neon Evolution

A premium, cinematic arcade experience built with Vanilla JS.

## 🚀 Features
- **PWA Ready**: Install as a standalone app on iOS/Android.
- **Cinematic Transitions**: State-based transitions for loading and game over.
- **Neon Aesthetic**: High-performance Canvas rendering with glow effects.
- **Responsive**: Dynamic scaling for both Desktop and Mobile.

## 🕹 Controls
- **PC**: WASD or Arrow Keys.
- **Mobile**: On-screen glassmorphism d-pad.

## 📱 iOS Installation
1. Open the GitHub Pages link in **Safari**.
2. Tap **Share** -> **Add to Home Screen**.

## 🛠 Deployment
1. Push this folder to a GitHub Repository.
2. Go to **Settings** > **Pages**.
3. Select the `main` branch and `/root`.
4. Your game is live!
