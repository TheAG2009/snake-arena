# 🐍 Snake Arena: AG Edition

A high-performance, neon-indie arcade game featuring organic snake movement.

## Credits
- **Project Concept & Logic**: AG
- **Visual Design**: Neon Evolution Suite

## Technologies
- HTML5 Canvas (Hardware Accelerated)
- Vanilla JavaScript (No Frameworks)
- PWA (Progressive Web App)

## Mobile Control Guide
Unlike traditional snake games, this version uses **Fluid Rotation**. 
- **PC**: Use 'A' and 'D' to rotate left and right.
- **Mobile**: Swipe your finger horizontally anywhere on the screen to steer.
